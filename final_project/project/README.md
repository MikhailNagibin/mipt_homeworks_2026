# Итоговый проект "GigaVibeMiptCode"

Консольный ИИ-ассистент с поддержкой контекста, работы с файлами и потоковой генерации ответов.

## Описание проекта

Проект представляет собой интерактивный интерфейс для взаимодействия с локальными или облачными языковыми моделями. Основные возможности:

- Управление контекстом: Автоматическое хранение и очистка истории сообщений при достижении лимитов.
- Работа с файлами: Вставка содержимого локальных файлов в запрос с помощью тега `@::путь_к_файлу::`.
- Стриминг: Вывод ответа модели в реальном времени.
- Режим чанкинга: Команда `/file_chunk` для обработки длинных текстов по частям (по абзацам или символам).

## Инструкция по запуску

### 1. Установка зависимостей

Для работы приложения установите библиотеки:

```bash
pip install openai pyyaml pytest pytest-cov ruff mypy
```

### 2. Подготовка модели

Приложение протестировано с использованием **Ollama**:

```bash
# Установка Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Загрузка модели
ollama pull gemma2:2b

# Запуск сервера (в отдельном терминале)
ollama serve
```

### 3. Настройка конфигурации

Создайте файл `config.yaml` в корне проекта.

**Пример содержания `config.yaml`:**

```yaml
api_key: "ollama"
api_host: "http://localhost:11434/v1/"
limit_message: 10
limit_chars: 4000
model_name: "gemma2:2b"
temperature: 0.7
system_prompt: "Ты — лаконичный ассистент."
```

### 4. Запуск приложения

Выполните команду из корня проекта:

```bash
python main.py
```

## Использование и команды

Взаимодействие с ассистентом происходит в режиме диалога через терминал.

### Специальные команды

| Команда | Описание |
|---------|----------|
| `\q` | Выход: корректное завершение работы приложения |
| `/reset` | Очистка: удаляет историю текущего диалога и очищает экран консоли |
| `/file_chunk` | Пакетная обработка: режим чтения длинных файлов по частям |

### Работа с файлами

Чтобы передать содержимое файла модели, используйте специальный тег прямо в тексте сообщения: `@::путь/к/файлу::`

**Пример:**

```
Что написано в этом конфиге? @::config.yaml::
```

### Режим `/file_chunk`

**Синтаксис:**
- `/file_chunk` — деление на абзацы
- `/file_chunk paragraph=3` — объединение по 3 абзаца
- `/file_chunk len=500` — деление по 500 символов
- `/file_chunk len=500 -y` — автоматический режим (без нажатия Enter)
